# techblogogy

Source for my blog: things I build and what they taught me.

Built with [Astro](https://astro.build). Posts are MDX files in `src/content/posts`.

```sh
pnpm install
pnpm dev      # local preview
pnpm build    # static site in dist/
```

- `labs/procedural-music/gen.py` generates the tracks in the procedural music post.
- `scripts/render_tonetech_clips.py` renders the ToneTech demo clips (run with ToneTech's venv).
